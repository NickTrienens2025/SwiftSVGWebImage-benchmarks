SDWebImageSVGCoder: memory profile

SDWebImageSVGCoder 1.8.0 / SDWebImage 5.21.7, through our actual ImageRenderingPipeline. 1200×900 target pixels, default Lanczos, three fresh release-test processes per asset/engine. Native comparisons cover only supported inputs. PNG texture remains ImageIO-based and is not upscaled.

RSS delta includes first-use framework/allocator allocations and a retained decoded output. Peak increase is the rise in process lifetime high-water mark over the pre-render high-water mark; it is not an exact operation peak. These values are not leak measurements or sums of cache costs. Queued results measure a different, warm multi-image workload. Source bytes are loaded locally; network time is excluded.
