# SwiftSVGWebImage benchmarks

Public static benchmark reports, SVG source fixtures, rendered images and supporting measurements. The Swift library source remains in its separate private repository.

[Open the benchmark site](https://nicktrienens2025.github.io/SwiftSVGWebImage-benchmarks/)

The snapshot was uploaded October 5, 2026. Reports preserve their original measurement dates and renderer configurations. Historical native-renderer and SDWebImageSVGCoder measurements are both included.

To browse locally, run `python3 -m http.server 8794 --bind 127.0.0.1` in this directory and open http://127.0.0.1:8794/.
